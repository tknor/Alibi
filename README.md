# Alibi

Alibi is a Spring Boot REST API built as a learning project.
A fictional criminal operations backend application.

## Run locally

Prerequisite: JDK 21.

```powershell
.\\gradlew.bat bootRun
```

Run the test suite with:

```powershell
.\\gradlew.bat test
```

## Project structure

```text
src/main/java/cz/tomas/alibi/       application code
src/main/resources/application.yaml application configuration
src/test/java/cz/tomas/alibi/       tests
build.gradle                        build and dependencies
```
